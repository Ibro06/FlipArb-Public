# Selected Public Code

The original FlipArb production repository remains private.

The public examples in this repository are intentionally simplified and use synthetic data. Their purpose is to demonstrate analytical reasoning and engineering structure without publishing production secrets.

Included examples:

* simplified opportunity scoring
* Bayesian Thompson Sampling query selection
* synthetic marketplace analysis notebook

The public examples do not contain API keys, OAuth tokens, private endpoints, webhook addresses, database credentials, or production user data.
