# Resume Bullets

## Analyst focused version

**FlipArb | Creator and Developer | 2026**

* Built a marketplace intelligence platform using Python and JavaScript that scanned more than 200,000 listings and combined comparable sales, repair pricing, device status, projected profit, ROI, confidence, risk, and liquidity signals to rank resale opportunities.
* Implemented a Bayesian Thompson Sampling learning system that rewarded higher quality search queries and dynamically reallocated scanner budget based on observed opportunity performance.
* Integrated eBay, MobileSentrix, SickW, and OpenAI APIs to support marketplace search, repair cost estimation, carrier lock verification, listing analysis, and automated opportunity alerts.
* Validated the workflow through real purchases by buying devices surfaced by the system, receiving them, and later reselling them.
